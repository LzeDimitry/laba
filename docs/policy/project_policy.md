## 1. Призначення проєкту

`Secure Update Client` — система доставки оновлень програмного забезпечення, яка
гарантує, що на робочу станцію буде встановлено лише той пакет, який підписаний
довіреним ключем розробника і не був змінений під час транспортування.

Ключова властивість продукту: **оновлення ніколи не застосовується без успішної
перевірки цифрового підпису та контрольної суми артефакту**.

## 2. Межі проєкту

До складу входять:

- `suc-client` — настільний клієнт (CLI + GUI);
- `suc-server` — REST API керування каналами та метаданими релізів;
- `suc-signer` — офлайн-утиліта підпису;
- сховище артефактів (CDN) — зовнішній сервіс.

Не входять: операційна система та її засоби захисту, фізичний доступ до
обладнання, внутрішня реалізація CDN-провайдера.

## 3. Мова та стек

- Мова реалізації: Python 3.12.
- Криптографія: лише перевірені бібліотеки (`cryptography`, `bcrypt`).
- Формат даних: JSON-манифести, підписані RSA-PSS (SHA-256) або Ed25519.
- VCS: Git, основна гілка `main`.

## 4. Правила ведення репозиторію

1. Прямі зміни `main` заборонені; зміни інтегруються через pull request.
2. Повідомлення комітів починаються з префікса: `[INIT]`, `[DOCS]`, `[FEAT]`,
   `[FIX]`, `[SEC]`, `[TEST]`.
3. Секрети (ключі, токени, паролі) не потрапляють у репозиторій та історію Git.
4. Кожна зміна коду супроводжується оновленням відповідного документа в `docs/`.

## 5. Вимоги до документації

- Документ без блоку метаданих не вважається чинним.
- Зміна архітектури вимагає оновлення `security/threat_model.md`.
- Нова безпекова вимога фіксується в `security/security_requirements.md` з
  унікальним ідентифікатором `SR-XX`.

## 6. Використання ШІ-агентів

Генеративний ШІ допускається в агентному режимі за умови, що автор зміни
розуміє кожен згенерований артефакт, перевіряє його та несе відповідальність
за результат. ШІ-агент не приймає рішень про послаблення безпекових вимог.

## 7. Порядок змін політики

Політика змінюється окремим комітом `[DOCS]` з підвищенням версії. У разі
суперечності між документами застосовується суворіше обмеження до моменту
узгодження.
