# Secure Update Client

Клієнт безпечного оновлення програмного забезпечення: перевіряє наявність
оновлень, завантажує підписаний пакет, перевіряє його автентичність і цілісність
та застосовує оновлення з можливістю відкату.

## Склад системи

| Компонент | Призначення |
| --- | --- |
| `suc-client` | Настільний клієнт: перевірка версій, завантаження, верифікація, встановлення |
| `suc-server` | REST API: канали оновлень, метадані релізів, облікові записи операторів |
| `suc-signer` | Офлайн-утиліта підпису релізів (приватний ключ у КХС) |
| package store | Сховище релізних артефактів (CDN) |
